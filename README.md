# Organisation du portfolio

## Pages principales

- `sommaire.php` : page d'accueil du portfolio.
- `index.html` : version statique de la page d'accueil pour GitHub Pages.
- `presentation.php` : presentation personnelle.
- `cv.php` : CV sous forme de page.
- `entreprise.php` : presentation de l'entreprise.
- `portfolio.php` : presentation du site portfolio.
- `e5.php` : tableau de synthese et elements E5.
- `e6.php` : missions professionnelles avec preuves.
- `veille.php` : veille technologique Ansible.
- `smr.css` : style commun du portfolio.

## Dossiers

- `assets/images/` : images utilisees par les pages principales.
- `assets/preuves/` : preuves affichees dans E6.
- `archive/` : anciens fichiers gardes au cas ou, mais non utilises par le portfolio actuel.

## Mise en ligne GitHub Pages

Pour mettre le portfolio en ligne sur GitHub Pages, utilise les fichiers `.html`, `smr.css` et le dossier `assets/`.

Etapes :

1. Creer un depot GitHub.
2. Envoyer tous les fichiers du portfolio sur GitHub.
3. Aller dans `Settings` > `Pages`.
4. Choisir la branche principale, puis le dossier racine.
5. L'URL du portfolio ouvrira automatiquement `index.html`.

Les fichiers `.php` peuvent rester dans le dossier, mais GitHub Pages utilisera surtout les fichiers `.html`.
